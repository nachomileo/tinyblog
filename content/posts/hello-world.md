This is **tinyblog**: a (maybe too) simple blog that reads markdown files from a folder and renders them that I set up trying to get rid of wordpress, databases and complex stuff just for writing.

Write your own posts by adding `.md` files to the `content/posts` folder. Each file should have frontmatter with `title`, `date`, and optionally `excerpt`.

## Features

- Write posts in markdown
- Automatic date sorting
- Clean, readable typography
- Fast and lightweight
