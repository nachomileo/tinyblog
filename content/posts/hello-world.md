Welcome to my **minimalistic blog**. This is a simple blog that reads markdown files from a folder and renders them beautifully.

## Features

- Write posts in markdown
- Automatic date sorting
- Clean, readable typography
- Fast and lightweight

## Code Example

```javascript
const greeting = "Hello, World!";
console.log(greeting);
```

## What's Next

Start writing your own posts by adding `.md` files to the `content/posts` folder. Each file should have frontmatter with `title`, `date`, and optionally `excerpt`.

Happy writing!
