# Getting Started with Markdown

Writing posts for this blog is simple. Just create a new `.md` file in the `content/posts` folder.

## Frontmatter

Each post should start with frontmatter:

```yaml
---
title: Your Post Title
date: 2026-04-15
excerpt: A brief description of your post.
---
```

## Markdown Syntax

You can use all standard markdown:

- **Bold text** with `**double asterisks**`
- *Italic text* with `*single asterisks*`
- [Links](https://example.com) with `[text](url)`
- Images with `![alt](url)`

### Lists

1. First item
2. Second item
3. Third item

### Blockquotes

> This is a blockquote. It's great for highlighting important information.

## That's It

The blog automatically picks up new files and sorts them by date. Simple and effective.
